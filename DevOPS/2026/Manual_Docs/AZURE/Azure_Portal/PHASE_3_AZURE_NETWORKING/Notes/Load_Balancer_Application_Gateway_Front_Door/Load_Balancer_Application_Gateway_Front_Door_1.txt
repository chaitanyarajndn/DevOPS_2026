			AZURE NETWORKING
			│
			├── 0. OSI MODEL FOUNDATION
			│   │
			│   ├── What is OSI Model?
			│   │   ├── Networking reference model with 7 layers.
			│   │   ├── Standardizes communication between systems.
			│   │   ├── Helps in troubleshooting network issues.
			│   │   └── Azure networking concepts are often mapped to OSI layers.
			│   │
			│   ├── Layer 4 (Transport Layer)
			│   │   ├── Works with TCP and UDP protocols.
			│   │   ├── Uses IP addresses and port numbers.
			│   │   ├── Cannot inspect URLs or HTTP headers.
			│   │   └── Azure Load Balancer operates at this layer.
			│   │
			│   ├── Layer 7 (Application Layer)
			│   │   ├── Understands HTTP and HTTPS traffic.
			│   │   ├── Can inspect URLs and hostnames.
			│   │   ├── Supports intelligent routing decisions.
			│   │   └── App Gateway and Front Door operate here.
			│   │
			│   ├── Layer 4 vs Layer 7
			│   │   ├── Layer 4 = IP + Port based decisions.
			│   │   ├── Layer 7 = URL + Hostname based decisions.
			│   │   ├── Layer 4 is faster and simpler.
			│   │   └── Layer 7 is smarter and feature rich.
			│   │
			│   ├── Interview Points
			│   └── Common Mistakes
