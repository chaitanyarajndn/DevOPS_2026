

========================================================================================================================
SELECTOR vs TEMPLATE
========================================================================================================================

TEMPLATE                                                                 | SELECTOR
-------------------------------------------------------------------------|----------------------------------------------------------
Purpose : Creates NEW Pods.                                              | Purpose : Finds existing Pods.
Think   : Blueprint / Design of Pod.                                     | Think   : Search Filter / Finder.
Works On: Future Pods.                                                   | Works On: Existing Pods.
Action  : Writes Labels on Pods.                                         | Action  : Reads Labels from Pods.
Used By : ReplicaSet while creating Pods.                                | Used By : ReplicaSet while counting/managing Pods.

========================================================================================================================
TEMPLATE
========================================================================================================================

Definition : Template defines HOW every new Pod should be created.

Example
-------
template:
  metadata:
    labels:
      app: nginx
  spec:
    containers:
    - name: nginx
      image: nginx:latest

Meaning
-------
Whenever ReplicaSet needs a new Pod, it copies everything from the Template.

Flow
----
Template
    │
    ├──────────────► Pod-1 (app=nginx)
    ├──────────────► Pod-2 (app=nginx)
    └──────────────► Pod-3 (app=nginx)

Template contains
-----------------
• Labels
• Containers
• Images
• Ports
• Volumes
• Environment Variables
• Restart Policy

Easy Remember
-------------
Template = HOW TO CREATE PODS

========================================================================================================================
SELECTOR
========================================================================================================================

Definition : Selector identifies WHICH Pods belong to this Deployment.

Example
-------
selector:
  matchLabels:
    app: nginx

Meaning
-------
Search every Pod whose label is

app = nginx

Cluster
-------
Pod-1   app=nginx
Pod-2   app=apache
Pod-3   app=nginx
Pod-4   app=mysql

Selector
--------
app=nginx

Result
------
✔ Pod-1
✔ Pod-3

Selector NEVER creates Pods.
Selector ONLY finds matching Pods.

Easy Remember
-------------
Selector = WHICH PODS ARE MINE?

========================================================================================================================
HOW TEMPLATE & SELECTOR WORK TOGETHER
========================================================================================================================

Template
    │
    │ Creates Pods with label
    ▼
Pod-1  app=nginx
Pod-2  app=nginx
Pod-3  app=nginx
    ▲
    │ Reads Labels
    │
Selector (app=nginx)
    │
    ▼
ReplicaSet knows
Current Pods = 3

========================================================================================================================
WHY BOTH ARE NEEDED?
========================================================================================================================

Template answers  : "How should I create a new Pod?"
Selector answers  : "Which Pods belong to me?"

Without Template  → Kubernetes cannot create a new Pod.
Without Selector  → Kubernetes cannot identify or count its Pods.

========================================================================================================================
REAL FLOW
========================================================================================================================

Deployment
    │
    ▼
ReplicaSet
    │
    ├── Uses Template ─────────► Creates New Pods
    │
    └── Uses Selector ─────────► Finds Existing Pods
                                     │
                                     ▼
                          Current Pods = 2
                          Desired Pods = 3
                                     │
                                     ▼
                             Create 1 More Pod

========================================================================================================================
IMPORTANT
========================================================================================================================

Template writes Labels.
Selector reads Labels.

template.metadata.labels
          MUST MATCH
selector.matchLabels

Otherwise ReplicaSet cannot properly manage Pods.

========================================================================================================================
MEMORY TRICK
========================================================================================================================

Template  = CREATE
Labels    = IDENTITY
Selector  = SEARCH
ReplicaSet= COUNT
Deployment= MANAGE
