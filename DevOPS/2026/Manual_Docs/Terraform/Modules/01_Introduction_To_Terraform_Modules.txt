What is a Terraform Module?
----------------------------------------------------------

Terraform Module ek reusable collection of Terraform configuration files hota hai.

Simple language me bole to,

"Ek module multiple Terraform resources ko ek reusable package me convert kar deta hai, jise hum baar-baar different projects ya environments me use kar sakte hain."


----------------------------------------------------------
Real Life Example
----------------------------------------------------------

Maan lo tum ek construction company me kaam karte ho.

Har naye project me tumhe same type ka house banana hai.

Har house me same cheeze hongi:

- Bedroom
- Kitchen
- Bathroom
- Parking

Ab do options hain.

Option 1

Har baar naye project ke liye poora design dobara banao.

Result

- Time waste
- Same work repeat hoga

- Maintenance difficult hogi


Option 2

Ek standard blueprint bana lo.

Ab jab bhi naya project aaye,
usi blueprint ko use karo.

Sirf ye change karo

- House Name
- House Size
- Paint Color
- Number of Rooms

Bas.

Yehi concept Terraform Module ka hai.

----------------------------------------------------------
Interview Definition
----------------------------------------------------------

Terraform Module is a reusable collection of Terraform configuration files.

It helps us avoid duplicate code by creating reusable infrastructure components.

Instead of writing the same resources multiple times, we create them once inside a module and reuse them across different environments by passing different input values.

This improves consistency, simplifies maintenance, and makes infrastructure easier to manage.

----------------------------------------------------------
Important Note
----------------------------------------------------------

A Module is NOT a new Terraform resource.

A Module is simply a folder that contains Terraform files such as

main.tf

variables.tf

outputs.tf

These files work together to create reusable infrastructure.
