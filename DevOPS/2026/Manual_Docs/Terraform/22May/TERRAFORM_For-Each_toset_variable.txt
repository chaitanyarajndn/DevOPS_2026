══════════════════════════════════════════════════════════════════════════════════════════════════════
📌 WHY each.key WORKS HERE ?
══════════════════════════════════════════════════════════════════════════════════════════════════════

Because SET contains only UNIQUE VALUES.

Example SET:
   {"rg1","rg2","rg3"}

Terraform internally treats:
   KEY   = VALUE

So:
   each.key   = rg1
   each.value = rg1

Both same in SET.
