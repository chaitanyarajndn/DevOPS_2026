📘 WHAT IS ITERATION ?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

➤ Iteration means repeating same task multiple times.
➤ Terraform performs same operation for different values.
➤ One value is picked at a time during iteration.
➤ Iteration reduces manual repetitive coding.
➤ `for_each` is Terraform’s iteration mechanism.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

➤ Same task repeats multiple times.
➤ Current value changes every iteration.
➤ Makes Terraform code shorter and cleaner.
➤ Helps automate infrastructure creation.
➤ Reduces duplicate coding effort.

    for safe resource tracking."

   "I may get confused
    while managing infrastructure."


That is why Terraform mainly prefers:

   ✅ Map
   ✅ Set


Because both provide UNIQUE IDENTITIES.

📘 LIST vs SET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LIST
────

➤ Ordered collection
➤ Duplicate allowed
➤ Not safe for for_each
➤ Tracking issue possible
➤ Used mainly with indexing



SET
───

➤ Unordered collection
➤ Duplicate NOT allowed
➤ Keeps only UNIQUE values
➤ Safe for for_each
➤ Best for resource tracking
