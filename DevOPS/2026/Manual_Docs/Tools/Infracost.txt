========================================================================================================================

1. Definition
------------------------------------------------------------------------------------------------------------------------
• Infracost is an open-source FinOps tool used to estimate cloud infrastructure cost before deployment.
• It works with Infrastructure as Code (IaC) tools like Terraform.
• It analyzes the Terraform Plan and estimates the expected cloud cost.
• It does NOT create, modify or delete cloud resources.
• It helps engineers understand the financial impact before infrastructure is deployed.

Quick Remember
Terraform  → What infrastructure will be deployed?
Infracost  → How much will that infrastructure cost?

------------------------------------------------------------------------------------------------------------------------
2. Purpose
------------------------------------------------------------------------------------------------------------------------
Terraform Shows                                      Infracost Shows
✔ Resources to Create                                ✔ Hourly Cost
✔ Resources to Update                                ✔ Monthly Cost
✔ Resources to Delete                                ✔ Yearly Cost
                                                     ✔ Cost Difference

In short, Terraform tells WHAT will change, while Infracost tells HOW MUCH those changes will cost.

------------------------------------------------------------------------------------------------------------------------
3. Why Do We Need Infracost?
------------------------------------------------------------------------------------------------------------------------
Problem
Developer increases infrastructure size without knowing the cost.

Example
• Standard_D2s_v5 VM  → Standard_D8s_v5 VM
• Premium SSD added
• NAT Gateway added

Terraform successfully deploys everything, but the monthly cloud bill increases significantly.

Solution
Run Infracost before deployment to estimate the cost and review expensive resources before approval.

Workflow

Terraform Code
      │
terraform plan
      │
terraform show -json
      │
infracost scan
      │
Review Estimated Cost
      │
terraform apply

Benefits
✔ Prevent unexpected cloud bills.
✔ Compare infrastructure cost before deployment.
✔ Choose smaller or cheaper resources if needed.
✔ Improve cost visibility during code review.

8. Commands (v2.12.2)
------------------------------------------------------------------------------------------------------------------------

General Commands

infracost --version                                            → Display the installed Infracost version.
infracost setup                                                → Perform first-time CLI setup.
infracost auth login                                           → Login to your Infracost account.
infracost auth whoami                                          → Show the currently logged-in user.
infracost auth logout                                          → Logout from Infracost.
infracost doctor                                               → Verify CLI configuration and diagnose issues.
infracost update                                               → Update Infracost to the latest version.
infracost --help                                               → Display all available commands.

Terraform Workflow

terraform init                                                → Download and initialize Terraform providers.
terraform validate                                            → Validate Terraform configuration.
terraform plan                                                → Generate the execution plan.

infracost scan .                                              → Scan the Terraform project and estimate cloud costs.
infracost scan . --json > infracost-report.json               → Save the scan result as a JSON report.

infracost inspect --summary                                   → Display a summary of the latest scan.
infracost inspect                                             → View detailed scan results.
infracost inspect --top 10                                    → Show the top 10 most expensive resources.
infracost inspect --total-savings                             → Display potential cost savings.

terraform apply                                               → Deploy the reviewed infrastructure.

infracost doctor                                              → Diagnose CLI configuration and installation issues.
infracost update                                              → Update Infracost to the latest version.
infracost auth logout                                         → Logout from the current account.
infracost --help                                              → Display all available commands.

5. How Infracost Works
------------------------------------------------------------------------------------------------------------------------

Terraform Code
      │
terraform plan
      │
Terraform Binary Plan
      │
terraform show -json
      │
Terraform Plan JSON
      │
infracost scan
      │
Reads Resource Configuration
      │
Matches Cloud Pricing Database
      │
Calculates Estimated Cost
      │
Generates Cost Report

The report can include:
• Hourly Cost
• Monthly Cost
• Yearly Cost
• Cost Breakdown per Resource
• Total Estimated Infrastructure Cost

------------------------------------------------------------------------------------------------------------------------
6. What Infracost Can & Cannot Do
------------------------------------------------------------------------------------------------------------------------

Can Do
✔ Estimate infrastructure cost.
✔ Analyze Terraform plans.
✔ Generate cost reports.
✔ Compare infrastructure cost before deployment.
✔ Integrate with CI/CD pipelines.

Cannot Do
✘ Create cloud resources.
✘ Modify infrastructure.
✘ Delete resources.
✘ Replace Terraform.
✘ Monitor actual cloud billing.

Quick Remember

Terraform  → Infrastructure Deployment
Infracost  → Infrastructure Cost Estimation

14. Limitations
------------------------------------------------------------------------------------------------------------------------

• Estimates cost only; it does not calculate the actual cloud bill.
• Actual billing can vary due to:
  • Reserved Instances
  • Savings Plans
  • Discounts
  • Data Transfer
  • Runtime Usage
  • Taxes
• Pricing depends on supported Terraform resources.

17. Common Interview Questions
------------------------------------------------------------------------------------------------------------------------

Q1. What is Infracost?
Ans:
Infracost is an open-source FinOps tool that estimates cloud infrastructure costs from Terraform plans before deployment.

------------------------------------------------------------------------------------------------------------------------

Q2. Why do we use Infracost?
Ans:
To understand the financial impact of infrastructure changes before deployment and avoid unexpected cloud costs.

------------------------------------------------------------------------------------------------------------------------

Q3. Does Infracost replace Terraform?
Ans:
No.
Terraform provisions infrastructure.
Infracost estimates the infrastructure cost.

------------------------------------------------------------------------------------------------------------------------

Q4. Does Infracost create cloud resources?
Ans:
No.
It only reads the Terraform plan and generates cost estimates.

------------------------------------------------------------------------------------------------------------------------

Q5. When should Infracost be executed?
Ans:
After "terraform plan" (or Terraform Plan JSON) and before "terraform apply".

------------------------------------------------------------------------------------------------------------------------

Q6. Can Infracost be integrated into CI/CD?
Ans:
Yes.
It integrates with Azure DevOps, GitHub Actions, GitLab CI/CD and Jenkins to provide cost visibility before deployment.

------------------------------------------------------------------------------------------------------------------------

Q7. Which cloud providers are supported?
Ans:
Microsoft Azure, Amazon Web Services (AWS) and Google Cloud Platform (GCP).

------------------------------------------------------------------------------------------------------------------------
18. One-Minute Interview Answer
------------------------------------------------------------------------------------------------------------------------

"Infracost is an open-source FinOps tool that estimates cloud infrastructure costs before deployment. It works with Terraform by analyzing the Terraform plan and calculating the expected cloud cost using cloud pricing data. It helps engineers review the financial impact of infrastructure changes before running terraform apply. Infracost is commonly integrated into Azure DevOps, GitHub Actions, GitLab CI/CD and Jenkins to improve cost visibility, prevent unexpected cloud bills and support cost-aware infrastructure decisions."
