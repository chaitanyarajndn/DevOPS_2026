1. MICROSOFT DEFENDER FOR CLOUD
═══════════════════════════════════════════════════════════════════════════════
WHAT IS IT?
→ Microsoft Defender for Cloud is a cloud security service that helps assess
  the security posture of Azure/cloud resources and protect workloads.
SIMPLE MEANING:
→ "Is my Azure environment secure?"
→ "What security weaknesses exist?"
→ "What should I fix?"
→ "Are my workloads exposed to security threats?"
THINK OF IT AS:
→ SECURITY POSTURE + RECOMMENDATIONS + WORKLOAD PROTECTION
───────────────────────────────────────────────────────────────────────────────
EXAMPLE:
Azure VM
  │
  ├──► Configuration
  ├──► OS / Software
  ├──► Network exposure
  └──► Security signals
             │
             ▼
     Defender for Cloud
             │
       ┌─────┴─────┐
       ▼           ▼
    Assess       Protect
       │           │
       ▼           ▼
 Recommendations  Threat protection
───────────────────────────────────────────────────────────────────────────────
WHAT CAN IT FIND?
→ Vulnerable configuration
→ Security recommendations
→ Missing security controls
→ Unnecessary exposure
→ Workload security issues
→ Security alerts
IMPORTANT:
→ Defender for Cloud is NOT simply a firewall.
→ It does not normally sit in the network traffic path.
→ It evaluates and protects Azure/cloud resources.
───────────────────────────────────────────────────────────────────────────────
MAIN DEFENDER FOR CLOUD CONCEPTS — WE WILL LEARN LATER:
→ CSPM                         → Secure Score
→ Security Recommendations    → Regulatory Compliance
→ Defender Plans               → Workload Protection
→ Defender for Servers         → Defender for Containers
→ Defender for Storage         → Defender for SQL
→ Defender for Key Vault       → Security Alerts

2. MICROSOFT SENTINEL
═══════════════════════════════════════════════════════════════════════════════
WHAT IS IT?
→ Microsoft Sentinel is a cloud-native SIEM and SOAR solution.
SIEM = Security Information and Event Management
SOAR = Security Orchestration, Automation and Response
SIMPLE MEANING:
→ "Collect security events from different sources."
→ "Find suspicious activity."
→ "Investigate security incidents."
→ "Automate security response."
THINK OF IT AS:
→ CENTRAL SECURITY CONTROL ROOM
───────────────────────────────────────────────────────────────────────────────
EXAMPLE:
VM ──────────────────────┐
AKS ─────────────────────┤
Azure Firewall ──────────┤
Entra ID ────────────────┤
Key Vault ───────────────┤
Microsoft 365 ───────────┤
Other Sources ───────────┤
                         ▼
                   MICROSOFT SENTINEL
                         │
                ┌────────┼────────┐
                ▼        ▼        ▼
             Detect  Investigate Respond
───────────────────────────────────────────────────────────────────────────────
REAL-WORLD EXAMPLE:
User
 │
 ├──► Failed login
 ├──► Failed login
 ├──► Failed login
 ├──► Successful login
 └──► Suspicious activity
             │
             ▼
         Sentinel
             │
             ▼
      Detection / Alert
             │
             ▼
          Incident
             │
             ▼
       Investigation
             │
             ▼
          Response
───────────────────────────────────────────────────────────────────────────────
IMPORTANT:
→ Sentinel is NOT a firewall.
→ Sentinel does not normally sit between Internet and VM.
→ It analyzes security-related data/events collected from different sources.
───────────────────────────────────────────────────────────────────────────────

3. SECURITY MONITORING
═══════════════════════════════════════════════════════════════════════════════
WHAT IS IT?
→ Security Monitoring is the continuous process of watching infrastructure,
  logs and security events to detect, investigate and respond to issues.
IMPORTANT:
→ Security Monitoring is NOT one specific Azure service.
→ It is an overall process/capability.
SIMPLE MEANING:
→ "Continuously watch the environment."
───────────────────────────────────────────────────────────────────────────────
EXAMPLE:
Azure Infrastructure
 │
 ├──► VM
 ├──► AKS
 ├──► Firewall
 ├──► NSG
 ├──► Key Vault
 ├──► Storage
 ├──► SQL
 └──► Entra ID
          │
          ▼
       Logs / Events
          │
          ▼
   SECURITY MONITORING
          │
     ┌────┼────┬─────────┐
     ▼    ▼    ▼         ▼
   Detect Alert Investigate Respond
───────────────────────────────────────────────────────────────────────────────
AZURE MONITORING COMPONENTS:
→ Azure Monitor       = General monitoring / observability
→ Log Analytics       = Log collection + querying
→ Activity Log        = Subscription-level Azure operations
→ Resource Logs       = Logs generated by Azure resources
→ Defender for Cloud  = Security posture + workload protection
→ Sentinel            = Security event analysis + SIEM/SOAR
